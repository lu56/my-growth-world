## 技术选型

| 事项 | 方案 | 原因 |
|------|------|------|
| 图表绘制 | 纯 SVG + CSS | 不引入 ECharts/Chart.js，保持轻量，与像素风一致 |
| 照片上传 | multipart/form-data 直接上传到后端本地 | 单家庭私有部署，不需要 OSS/CDN |
| 照片压缩 | 前端 Canvas API 压缩 | 减少传输体积，避免超大照片 |
| 照片存储 | `backend/data/uploads/YYYY-MM/` | 与 SQLite 同目录，Docker 挂载卷一并持久化 |
| 骨架屏 | 纯 CSS animation | 零依赖 |
