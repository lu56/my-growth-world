## 4. PostgreSQL 兼容说明

- 所有表使用标准 SQLAlchemy 类型，无 SQLite 专有类型。
- 切换 PostgreSQL：修改 `.env` 中 `DATABASE_URL=postgresql+psycopg2://...`，并安装 `psycopg2`。
- 日期时间字段使用 `DateTime`（带时区感知），兼容两种数据库。
