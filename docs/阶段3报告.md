### 2.2 像素图标组件

**新增** `PixelIcon.vue` — SVG 像素图标系统，零图片文件：

- 使用 SVG `<rect>` 元素绘制 16×16 像素图案
- `shape-rendering="crispEdges"` 确保像素清晰不模糊
- 支持 5 种类型：
  - `avatar`：6 级角色头像（成长新人→森林探索者→矿洞学徒→铁甲战士→钻石守护者→传说英雄）
  - `gem`：魔法宝石图标
  - `badge`：4 档稀有度成就徽章（common/rare/epic/legendary）
  - `task`：5 种任务类型图标（学习/习惯/家务/品德/临时）
  - `reward`：4 种奖励图标（电视/平板/零食/玩具）
- 统一 `:size` 属性控制输出尺寸

### 2.3 音效系统

**新增** `sound.ts` — Web Audio API 8-bit 芯片音效：

- 使用 `OscillatorNode` + `GainNode` 生成方波/三角波/锯齿波
- ADSR 包络控制音量曲线
- 6 种音效：`gem`(加分)/`levelup`(升级)/`achievement`(成就)/`exchange`(兑换)/`click`(点击)/`penalty`(减分)
- 用户交互后自动 `audioCtx.resume()` 解决浏览器自动播放限制
- 前端 store 集成音效开关，可随时静音

### 2.4 动画效果系统

**更新** `GameEffectOverlay.vue` — 全局动画覆盖层：

- **等级升级动画**：金色卡片 + 20 颗金光散射粒子 + PixelIcon 角色头像浮动 + 弹跳入场
- **成就解锁动画**：稀有度光效边框 + conic-gradient 旋转背景 + 逐个展示多个成就
- **彩屑庆祝**：50 片随机色彩/形状/速度的彩屑自由落体
- **`achCardStyle` computed**：返回 `{ '--glow-color': rarity_glow }` 供 CSS 变量使用

**更新** `stores/effect.ts` — 动画状态管理：

- 集成音效触发（升级→levelup音效，成就→achievement音效）
- 彩屑动画触发
- 延迟序列：先展示成就弹窗，关闭后再展示等级升级弹窗
- `handleApiResponse()` 统一解析后端响应，提取 `level_change.level_up` 和 `new_achievements`

## 四、技术决策记录

| 决策 | 原因 |
|---|---|
| 纯 CSS/SVG 绘制像素图标 | ImageGen 生成的图片有 AI 水印；外部下载无法获取二进制文件；CC0 素材需联网下载。代码绘制零依赖、零版权、可维护 |
| Web Audio API 生成音效 | 同上，零音频文件，浏览器原生支持 |
| `achCardStyle` 用 computed 返回 CSS 变量 | Vue 模板编译器对内联 `:style="{ '--custom': ... }"` 解析异常，改用 computed 解决 |
| `RARITY_GLOW` 字典集中管理 | 统一稀有度颜色/标签/强度配置，`scores.py`/`rewards.py`/`achievements.py` 共享 |
