## 一、每日打卡挑战

### 1.1 设计思路

小朋友在** ChildHome 端**每天看到一组打卡任务（由家长在 ParentRules 中勾选"可打卡"的任务规则），逐个点击"打卡"。每项打卡即自动加分（复用 score_record），同时记录打卡状态。连续打卡天数达到里程碑（3/7/15/30天）自动发放额外宝石奖励。

- **谁能打卡**：小朋友自己在 ChildHome 端操作（不需要家长登录）
- **打卡任务来源**：家长在任务规则中勾选 `is_checkin = True` 的任务
- **每日限制**：每个打卡任务每天只能打一次
- **连续奖励**：3天+5宝石、7天+15宝石、15天+30宝石、30天+100宝石（里程碑达成时自动发放一次性奖励）

### 1.2 数据模型

**新增表 `daily_checkin`**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | |
| child_id | Integer FK→child.id, index | |
| task_rule_id | Integer FK→task_rule.id | 打卡对应的任务规则 |
| checkin_date | Date, not null | 打卡日期（仅日期，不含时间） |
| score_record_id | Integer, 可空 | 关联的加分流水ID |
| created_at | DateTime | |

**约束**：`(child_id, task_rule_id, checkin_date)` 唯一索引，防止同一天重复打卡。

**修改表 `task_rule`**：新增字段 `is_checkin` Boolean 默认 False，标记该任务是否可打卡。

**新增表 `checkin_streak`（连续打卡记录）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | |
| child_id | Integer FK→child.id, index | |
| task_rule_id | Integer FK→task_rule.id | |
| current_streak | Integer | 当前连续天数 |
| longest_streak | Integer | 历史最长连续 |
| last_checkin_date | Date | 上次打卡日期 |
| milestone_claimed | String(50) | 已领取的最高里程碑（"3"/"7"/"15"/"30"/""） |

### 1.3 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/checkin/today` | 获取今日打卡状态（哪些任务已打卡、当前连续天数） |
| POST | `/api/checkin/{task_rule_id}` | 执行打卡：加分+记录+检测里程碑→返回加分结果+里程碑奖励 |
| GET | `/api/checkin/history?days=30` | 获取近N天打卡日历（哪些天打了哪些卡） |

**打卡接口返回**（复用加分响应结构 + 打卡信息）：


## 二、孩子目标设定

### 2.1 设计思路

小朋友在 ChildHome 端可以自己设定成长目标，比如"这周读完一本课外书，攒50宝石买玩具"。目标包含：标题、描述、目标积分、截止日期。提交后状态为"待审批"，家长在 ParentDashboard 端审批通过后目标生效。孩子完成相关任务积累积分，系统自动检测目标是否达成，达成后自动发放奖励宝石并标记完成。

- **谁能设定**：小朋友自己在 ChildHome 端提交
- **审批流程**：待审批 → 已通过 / 已拒绝
- **达成判定**：目标通过后，从通过时间开始累计相关加分，达到目标积分即自动完成
- **奖励**：目标完成后额外发放目标积分的10%作为奖励（向上取整），培养"定目标→努力→达成"的闭环

### 2.2 数据模型

**新增表 `personal_goal`**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | |
| child_id | Integer FK→child.id, index | |
| title | String(100) | 目标标题 |
| description | String(500) | 目标描述 |
| target_score | Integer | 目标积分数 |
| bonus_score | Integer | 达成奖励（自动算 target_score * 10% 向上取整） |
| status | String(20) | pending/approved/rejected/completed |
| approved_at | DateTime, 可空 | 审批时间 |
| completed_at | DateTime, 可空 | 达成时间 |
| deadline | Date, 可空 | 截止日期 |
| progress_score | Integer | 已积累积分（通过后开始计算） |
| created_at | DateTime | |

### 2.3 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/goals` | 获取目标列表（含状态和进度） |
| POST | `/api/goals` | 孩子提交新目标（status=pending） |
| PUT | `/api/goals/{id}/approve` | 家长审批通过 |
| PUT | `/api/goals/{id}/reject` | 家长拒绝 |
| DELETE | `/api/goals/{id}` | 删除目标 |

**目标列表返回**：
```json
[{
  "id": 1, "title": "读完一本课外书", "description": "这周读完《小王子》",
  "target_score": 50, "bonus_score": 5, "status": "approved",
  "progress_score": 30, "progress_ratio": 0.6,
  "deadline": "2026-09-07", "approved_at": "...", "completed_at": null
}]
```
