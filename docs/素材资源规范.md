# 《我的成长世界》素材资源规范

## 目录结构

系统素材统一存放于 `frontend/public/assets/` 下，按功能分类：

```
frontend/public/assets/
├── avatar/       # 角色头像（含等级头像）
├── gem/          # 魔法宝石图标
├── badge/        # 成就徽章
├── ui/           # UI 元素（任务图标、按钮、面板）
├── buildings/    # 建筑装饰
└── sounds/       # 音效
```

## 资源映射约定

代码中**不硬编码图片路径**，统一通过 `src/utils/resources.ts` 的资源映射表引用。

例如等级配置：
```ts
levelIconMap: {
  level_1: '/assets/avatar/level_1.png',
  ...
}
```

后端在数据库存储的是**资源键**（如 `level_3.png`、`task_homework.png`），前端根据键在映射表中解析出真实路径。这样更换素材只需替换资源库文件，无需改动代码。

## 本阶段说明（阶段1）

阶段1 聚焦数据模型、后端接口、基础页面，素材使用 **emoji + CSS 像素风格** 占位。阶段3 将接入真实 PNG 素材并启用音效与动画。资源映射表 `resources.ts` 已预留全部素材键，后续只需填入真实路径。

- 所有素材优先 CC0。
- 用 CC-BY 需保留署名。
- 不使用 Minecraft 官方 Logo、Steve/Creeper 角色、官方 UI 与音效。
- 非 CC0 音效需确认授权并注明出处。
